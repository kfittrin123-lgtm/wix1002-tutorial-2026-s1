### Question 6

### Question 7
7. Print the number of odd and even number from 10 random numbers generated by
computer. The random number must be from 10 – 100.
    IPO Table
    | Input | Process | Output |
    | :---: | :---: | :---:|
    | none | Repeat 10 times, generate RandomNumber from 10 - 100 and check each RandomNumber with modulus 0 to get result, Increase the evenNumber OR oddNumber based on the result | Display evenNumber AND oddNumber |
    Pseudocode
        Start
        Initialise n = 10
        Initialise evenNumber = 0
        Initialise oddNumber = 0
        While n <= 10
            Generate RandomNumber from 10 - 100
            if RandomNumber % 2 == 0
                evenNumber = evenNumber + 1
            else
                oddNumber = oddNumber + 1
            n = n + 1
        Display evenNumber, oddNumber
        Stop
    
    ```mermaid
    graph TD;
        Start(["Start"]) --> Process1["Initialise n = 10
        Initialise evenNumber = 0
        Initialise oddNumber = 0"];
        Process1 --> Decision1{n <= 10};
        Decision1 --true--> Decision2{"RandomNumber % 2 == 0"};
        Decision1 --false--> Output[/"Display evenNumber, oddNumber"/];
        Decision2 --true--> Process2["evenNumber = evenNumber + 1"];
        Decision2 --false--> Process3["oddNumber = oddNumber + 1"];
        Process4["n = n + 1"];
        Process2 --> Process4;
        Process3 --> Process4;
        Process4 --> Decision1;
        Output --> Stop(["Stop"]);
    ```

### Question 8
8. Count the number of alphabet U and M from a sentence entered by user.
    IPO Table
    | Input | Process | Output |
    | :---: | :---: | :---: |
    | Sentence | Increase CountU OR CountM based on letter in Sentence | Display CountU AND CountM|
    Pseudocode
        Start
        Get Sentence
        Initialise CountU = 0
        Initialise CountM = 0
        Assign counter to each letter in Sentence
        while counter <= Sentence.length - 1
            if letter.equals(U)
                CountU = CountU + 1
            if else letter.equals(M)
                CountM = CountM + 1
            counter = counter + 1
        Display CountU, CountM
        Stop
    
    ```mermaid
    graph TD;
        Start(["Start"]) --> Input[/"Get Sentence"/];
        Input --> Process1["Initialise CountU = 0
        Initialise CountM = 0
        Assign counter to each letter in Sentence"];
        Process1 --> Decision1{"counter <= Sentence.length - 1"};
        Decision1 --true--> Decision2{"letter.equals(U)"};
        Decision2 --true--> Process2["CountU = CountU + 1"];
        Decision2 --false--> Decision3{"letter.equals(M)"};
        Decision3 --true--> Process3["CountM = CountM + 1"];
        Process4["counter = counter + 1"];
        Process2 --> Process4;
        Process3 --> Process4;
        Decision3 --false--> Process4;
        Process4 --> Decision1;
        Decision1 --false--> Output[/"Display CountU, CountM"/];
        Output --> Stop(["Stop"]);
